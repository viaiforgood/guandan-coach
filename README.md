## 📖 项目简介 (Overview)

**掼蛋大师教练 (Guandan Pro Coach)** 是由 **唯爱AI公益基金会 (VI AI for Good Foundation)** 发起、**浙大智能体 (ZJU AI Agent Lab)** 与 **北美高校联盟 掼蛋俱乐部 (NAACU Guandan Club)** 联合研发的专业级 AI 掼蛋教学、记牌算牌（五十定律）、残局闯关、战局复盘、专属牌背定制与多人联机平台。

## 🌟 核心功能矩阵 (Features)

### 1. 🏟️ 腾讯同款原生横屏竞技桌 (Tencent Native 16:9 Landscape Arena)
- **16:9 横屏同屏全景展示**：横屏状态下一屏同显【主对局桌 + AI大师教练实时支招 + 五十定律残局记牌器】，无需切换标签页或上下滚动！
- **竖屏零滚动自适应叠牌**：精准动态重叠算法，手机竖屏下 27 张手牌单列全览，彻底告别左右滑动找牌。
- **高清晰纯净牌面设计**：仅保留上方高对比度大字角标与花色，视觉清爽醒目不眼花。
- **3D 头像与倒计时光圈**：行动回合外圈倒计时环自动缩减，最后 5 秒变为警告玫瑰红。
- **四人标准 (2副牌·108张)** 与 **六人3v3团战 (3副牌·162张)** 全支持。

### 2. 🎴 初始组牌 3 选 1 体系 (3-Option Hand Grouping)
- **① 自然点数由大到小 (`1.由大到小`)**：大王 ➔ 小王 ➔ 红桃逢人配 ➔ 级牌 ➔ A ➔ K ... ➔ 2 连续平铺展开。
- **② AI教练建议组牌 (`2.教练建议`)**：依托博弈优化引擎自动聚类为最佳战术组合（炸弹群 🔥、同花顺、顺子、三连对、三带二、对子与单张）。
- **③ 玩家自由手动组牌 (`3.玩家组牌`)**：自选手牌点击【➕ 编入组】自由成套，支持单组一键拆解与一键还原。

### 3. 🎨 战队专属牌背与 Logo 定制工坊 (Card Back & Logo Customizer)
- **6 款名门赛事与高校联盟预设**：
  - 🎓 **北美高校联盟**（赤金深红 · NAACU GUANDAN CLUB）
  - 🏛️ **广州市中大校友会**（怀士堂墨绿 · SYSU ALUMNI）
  - 🦅 **浙大智能体**（求是深蓝 · ZJU AI LAB）
  - 🌟 **唯爱AI公益基金会**（官方金蓝科技）
  - 👑 **赤金至尊龙纹**（大师典藏赛）
  - 💎 **曜石黑金极光**（电竞极简风）
- **自由上传俱乐部图片 Logo 与战队队名**，实时 3D 渲染，全局对局牌桌立即换装！

### 4. 📚 掼蛋实战宝典库 (三大名家权威专区)
- 🏛️ **广州市中山大学校友会**：《掼蛋宝典》（18条黄金实战口诀原件与博弈论战术精解）
- 👑 **蒋主席**（北美高校联盟掼蛋俱乐部名誉主席）：《掼蛋实战宝典与博弈心法》（残局逆向预设、困死孤张、配角拯救大兵、50%过牌法则）
- 👩‍🏫 **慧姐**（北美高校联盟北加硅谷名宿）：《实战牌语与攻防心法》（首发小单强牌信号、对子探路、多炸主攻单炸僚机）
- 每条口诀支持**一键复制微信朋友圈与微信群分享格式**。

### 5. 🎵 Suno 原创国风战歌电台 (145首全集)
- 完整收录《汉风·满江红·掼蛋出征》、《道兵合一》、《掼战风云》等 145 首原创国风激昂战歌。
- 支持曲目搜索、后台播放、智能循环与悬浮抽屉切歌。

### 6. 🏆 玩家段位成长与 6 位免密云端同步 (EXP & Rank Ladder)
- **5 大荣耀段位**：`🌱 初级学徒` ➔ `⚔️ 进阶好手` ➔ `🔥 竞技精英` ➔ `👑 省级国手` ➔ `🏆 传奇特级大师`。
- **多维战绩雷达**：总场次、胜率、头游登顶率、换位复赛翻盘胜率、炸弹数量全面记录。
- **6 位专属免密同步码**：手机、平板与电脑一秒跨端迁移战绩！

### 7. 🎬 牌谱智能复盘系统 (Match Replay & Analyzer)
- **逐步时间轴推演**：支持任意步骤 ($0 \dots N$) 自由滑动与 1.0x / 1.5x / 3.0x 自动播放。
- **招法质量剖析与失误诊断**：即时标注压牌合理性、控权时机与战术漏洞。
- **牌谱导入与导出 (JSON)**：支持一键导出复制或导入外部 `.guandan.json` 牌谱。

### 8. 🌐 四人/六人在线 P2P 联机对战 (WebRTC Multiplayer)
- 基于 **WebRTC (PeerJS)** 的去中心化无服务器房间对战体系。
- 房间码一键创建与加入（如 `8888`），空缺席位自动由国手级 AI NPC 替补。

### 9. 🧠 五十定律记牌算牌特训营 (50-Law Tracker HUD)
- **五十定律实战监控**：实时追踪全场已出 5 与 10 的张数，5 与 10 是顺子的核心枢纽。
- **大王、小王、主级牌与登基牌实时追踪**，报单/报双高危警报。

## 🛠️ 技术栈与架构 (Tech Stack)

```text
guandan-coach/
├── src/
│   ├── core/           # 纯原生 TypeScript 掼蛋规则与博弈引擎 (无第三方游戏运行时)
│   │   ├── types.ts    # 游戏状态、牌型、牌谱与多人数据契约
│   │   ├── cards.ts    # 两副牌/三副牌洗牌、发牌、逢人配与排序算法
│   │   ├── combos.ts   # 牌型分类 (单/对/三/顺/钢板/三连对/炸弹/同花顺/天王炸)
│   │   ├── optimizer.ts# 启发式双向理牌算法 (保炸优先 vs 极度去单化)
│   │   ├── tracker.ts  # 五十定律与未见牌概率计算引擎
│   │   ├── ai.ts       # 三段位 AI 智能体决策系统
│   │   ├── baodian.ts  # 中大校友会18条口诀 + 蒋主席心法 + 慧姐心法数据库
│   │   ├── cardback.ts # 牌背预设与个性化定制系统
│   │   ├── bgm.ts      # Suno 145 首原创战歌目录与播放管理
│   │   ├── profile.ts  # 玩家段位、EXP战力成长与 6 位云端同步码
│   │   ├── engine.ts   # 轮转出牌、接风、进贡还贡与升级大满贯计分
│   │   ├── replay.ts   # 牌谱状态重构与战术解说引擎
│   │   ├── online.ts   # WebRTC P2P 多人房间管理器
│   │   ├── voice.ts    # Web Speech API 语音合成与表情互动
│   │   ├── audio.ts    # Web Audio API 牌桌音效发生器
│   │   └── i18n.tsx    # 简/繁/英多语言国际化上下文
│   ├── components/     # 现代化 UI 组件库 (PokerTable, Card, Modals, Coach, HUD, Bgm)
│   └── views/          # 实战、复盘、联机、残局、宝典、记牌、学院、识牌视图
```

## 🚀 快速上手与本地开发 (Quickstart)

```bash
# 克隆公开代码仓库
git clone https://github.com/viaiforgood/guandan-coach.git
cd guandan-coach

# 安装依赖
npm install

# 启动本地极速开发热重载服务器
npm run dev

# 运行单元测试 (100% 通过)
npm test

# 构建生产版本
npm run build
```

## 🌐 云端部署 (Deployment)

本项目专为 **Cloudflare Pages / Vercel** 边缘网络优化：

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) -> **Compute (Workers & Pages)** -> **Pages**。
2. 关联 GitHub 公开仓库 `viaiforgood/guandan-coach`。
3. 配置构建参数：
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. 点击 **Save and Deploy** 即可全球上线并绑定自定义域名 `guandan.weiai.ai`。
